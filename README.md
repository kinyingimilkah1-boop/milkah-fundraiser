# Milkah Fundraiser

A polished static fundraising landing page supporting Milkah's journey through medical school.

## Live Demo

[View the live Netlify demo](https://clinquant-yeot-9edf65.netlify.app/)

## Features

- Responsive fundraising landing page
- Story, impact, progress, testimonials, and FAQ sections
- Interactive donation amount selector
- PayPal donation redirect flow
- Direct Gmail contact link
- Responsive design with animated visual effects

## Files

- `index.html` - Page structure and fundraiser content
- `styles.css` - Visual design, responsive layout, and animations
- `script.js` - Donation amount selection and PayPal redirect behavior

## Run Locally

Open `index.html` in a web browser, or serve this folder with any static web server.

## Deployment

This project is ready for static hosting on Netlify, GitHub Pages, Vercel, or another static hosting provider.

Before accepting donations, replace the PayPal placeholder in `script.js` with the real PayPal business email or donation URL.
